# For Queen

Personal birthday site.

```bash
npm install
npm run dev
```

Open http://localhost:3000. The lock code is `0702`.

Put the photograph at `public/images/queen.jpg` and the song at `public/audio/birthday-song.mp3`.

Set `FRIENDSHIP_START_YEAR` in `src/config/queen.ts` when the year is known.

Deploy by importing the project on Vercel. No extra environment variables are required.
